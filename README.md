# CarePulse Frontend

Next.js (App Router) + TypeScript + Tailwind client for the CarePulse / MedVault API.

## Setup
1. `npm install`
2. Copy `.env.example` to `.env.local`
3. Start the backend on port 5000
4. `npm run dev` then open http://localhost:3000

## Roles
- Patient: profile, emergency QR, SOS, records, appointments
- Responder: live alerts
- Doctor: appointments and patient records
- Admin: staff and hospitals
